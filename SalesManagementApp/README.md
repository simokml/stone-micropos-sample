# 📦 تطبيق إدارة المبيعات (نسخة سطح المكتب)

تطبيق "إدارة المبيعات" هو برنامج مكتبي مكتمل الوظائف يُستخدم لتتبع وتنظيم عمليات البيع والشراء داخل المتاجر الصغيرة والمتوسطة.

## 🎨 مميزات التصميم

- **التصميم الداكن**: واجهة أنيقة باللون الأسود لراحة العين
- **دعم اللغة العربية**: واجهة مستخدم باللغة العربية مع اتجاه النص من اليمين لليسار
- **تصميم عصري**: واجهة بسيطة واحترافية وسهلة الاستخدام
- **قائمة جانبية**: تنظيم الأقسام في قائمة جانبية على الجهة اليمنى

## 🧩 أقسام البرنامج

### الرئيسية
- لوحة تحكم تعرض ملخصًا لحالة المبيعات
- عرض الديون والأرباح اليومية
- إحصائيات سريعة

### فاتورة المبيعات
- إمكانية إصدار فواتير بسرعة
- اختيار العميل وإدخال المنتجات
- حساب الكمية والسعر والخصم
- حساب الإجمالي والطباعة أو الحفظ كـ PDF

### العملاء
- إضافة وتعديل بيانات العملاء
- معلومات شاملة: الاسم، الهاتف، العنوان، الرصيد الحالي
- عرض سجل المبيعات والدفع لكل عميل

### الموردون
- تسجيل الموردين وتتبع المشتريات
- متابعة المبالغ المستحقة لهم
- إدارة علاقات الموردين

### المخزون
- عرض وإدارة قائمة المنتجات
- تحديث الكمية تلقائيًا بعد البيع أو الشراء
- تنبيهات عند انخفاض كمية منتج
- إدارة الباركود والفئات

### التقارير
- تقارير مبيعات يومية، أسبوعية، شهرية
- تصدير التقارير بصيغ Excel أو PDF
- تحليلات مالية وإحصائية

### الإعدادات
- ضبط العملة والضريبة واللغة
- إعدادات واجهة الطباعة
- تخصيص النظام

### النسخ الاحتياطي
- إنشاء نسخ احتياطية من قاعدة البيانات
- خيار استعادة النسخة عند الحاجة
- حماية البيانات

## ⚙️ المواصفات الفنية

- **لغة البرمجة**: C# مع .NET Framework 4.5.2
- **واجهة المستخدم**: WPF (Windows Presentation Foundation)
- **قاعدة البيانات**: SQLite
- **بيئة التشغيل**: Windows
- **نوع التطبيق**: Desktop Application

## 🏗️ بنية المشروع

```
SalesManagementApp/
├── Models/           # نماذج البيانات
│   ├── Customer.cs
│   ├── Product.cs
│   ├── Invoice.cs
│   └── InvoiceItem.cs
├── Views/            # واجهات المستخدم
│   └── MainWindow.xaml
├── Services/         # خدمات البيانات
│   └── DatabaseService.cs
├── Styles/           # أنماط التصميم
│   ├── DarkTheme.xaml
│   ├── ButtonStyles.xaml
│   └── TextBoxStyles.xaml

└── Resources/        # الموارد والأيقونات
```

## 🚀 كيفية التشغيل

1. **متطلبات النظام**:
   - Windows 7 أو أحدث
   - .NET Framework 4.5.2 أو أحدث

2. **التثبيت**:
   - قم بتحميل الملفات
   - افتح المشروع في Visual Studio
   - قم ببناء المشروع (Build)

3. **التشغيل**:
   - شغل التطبيق من Visual Studio أو
   - شغل الملف التنفيذي من مجلد bin

## 📊 قاعدة البيانات

يستخدم التطبيق قاعدة بيانات SQLite مع الجداول التالية:

- **Customers**: بيانات العملاء
- **Products**: بيانات المنتجات
- **Invoices**: الفواتير
- **InvoiceItems**: عناصر الفواتير
- **Settings**: إعدادات النظام
